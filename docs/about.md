# 关于本教程

## 一句话

《从编码到行动》希望用一条连续叙事，把机器人世界模型需要的表征、预测、语言、动作、规划与闭环执行串起来。

## 为什么要做这套教程

机器人学习资料通常按模型名字组织：先出现 CLIP，再出现 Transformer，再出现 Diffusion Policy，读者很难回答一个更基本的问题——

> 为了让机器人理解当前世界、想象动作后果、并完成语言任务，每一个模块到底补上了哪一块能力？

本教程按能力缺口展开，而不是按论文发表顺序展开。

## 覆盖范围

内容方向包括：

- 机器人学习与表征学习
- 视觉、语言与动作的多模态建模
- VLM、VLA 与世界模型
- JEPA / V-JEPA / VLA-JEPA 等预测式表示
- 人形机器人操作中的规划、仿真与真机部署问题

当前版本已经完成基础篇七章正文、配套图示与可运行练习；进阶篇和高级篇仍在持续编写与验证。
