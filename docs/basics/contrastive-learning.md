# 对比学习

## 本章解决什么问题

有时我们并不想重建像素，而想让相关观测靠近、无关观测分开。本章引入对比学习，并为 CLIP 做准备。

- 正样本定义错误时，模型会把不该忽略的操作细节也抹掉
- 把对比学习得到的聚类直接当成动力学状态
