# 基础篇：世界如何被表示

核心问题：

> 图像、语言、机器人状态和动作，怎样变成模型内部可学习的表示？

如果模型还不能稳定地编码当前世界，后面的 Attention、生成模型和 VLA 都会建立在漂浮的特征上。基础篇先处理这件事。

## 本阶段要打通的能力

```text
现实世界如何变成数字
→ 数字如何变成特征
→ 特征如何表示当前状态
```

```mermaid
flowchart LR
    X["图像 / 语言 / 状态 / 动作"] --> E["编码器"]
    E --> Z["latent representation"]
    Z --> T["可训练、可比较、可预测"]
```

## 学完基础篇应该能解释

- [ ] 为什么机器人学习里几乎所有模块都先把输入写成张量

## 本阶段结束后留下的问题

即使已经有了当前时刻的表示 \(z_t = E(o_t)\)，模型仍然不知道：

- 哪些历史信息现在才重要？
- 世界会如何随动作变化？
- 未来是一条确定轨迹，还是多种可能？

这些问题交给 [进阶篇](../intermediate/index.md)。
