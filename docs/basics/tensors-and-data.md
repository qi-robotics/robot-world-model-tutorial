# 张量与数据

## 本章解决什么问题

机器人看到的是图像、关节角、语言指令和接触力，模型看到的必须是形状明确的数组。本章先解决：现实世界怎样被写成可计算的张量。

## 学习目标

完成本章后，读者应该能够：

- [ ] 说明观测、标签和批次如何变成张量
- [ ] 读懂 `[B, C, H, W]`、`[B, T, D]` 这类形状
- [ ] 解释为什么后续所有模块都要先约定形状

## 直观理解

把传感器读数看成有名字的多维数组：谁是批次，谁是时间，谁是通道，必须在进网络前说清楚。

## 输入、输出与张量形状

| 名称 | 符号 | 示例形状 | 含义 |
|---|---|---:|---|
| 图像 | o^{img} | [B, C, H, W] | 视觉观测 |
| 语言 token | o^{lang} | [B, L] | 离散 token id |
| 本体状态 | o^{prop} | [B, P] | 关节、端位姿等 |
| 动作 | a | [B, A] 或 [B, T, A] | 待执行或已执行动作 |
