# 04-5 视觉表征的任务检验与使用

04-2～04-4 的方法各有训练指标：像素重建误差、潜变量分布约束、样本相似度和目标特征误差。它们衡量的不是同一道题，所以不能把几条损失曲线画在一起，直接选最小者作为机器人视觉编码器。本节把比较标准转回任务：杯子是什么、在哪里，背景改变后答案是否仍可靠，编码结果有没有退化。

## 用同一组任务读取不同表征

先冻结各自训练好的编码器，不再用位置标签修改它们。取同样的训练图像与杯子中心标签，只训练一个简单的位置读出头 $\hat p=H(E(I))$，再在未见图像上测量坐标误差。这样问的是：“当前表示里的位置线索是否容易被读出来？”也可用相同方法读取目标颜色、夹爪附近遮挡或相邻两帧的移动方向，但每次都要明确读出头用了哪些输入。比较不同编码器时，数据划分、读出头能力和预处理应尽量一致；否则结果中混入的差别未必来自表征。

“容易读出”不是说每个特征维度都要有人工可命名的含义。若简单读出头在未见场景上已能稳定给出杯子中心，就说明这组信息对该任务比较可用。若必须靠复杂读出头在训练集上反复拟合、换一张桌布就失效，则不能仅因编码向量有很多维而宣称它保留了位置。

## 分别改变无关因素和任务因素

可以构造两组对照。第一组**固定红杯的位置**，改变桌布、亮度和蓝色干扰物：理想情况下，定位结果应基本不变。第二组**固定背景**，只把红杯从左移到右：预测位置应跟着移动。只做第一组，常数输出也可能显得稳定；只做第二组，又可能无法发现模型借背景猜位置。两组一起检查，才能问清编码器对什么保持稳定、对什么保持敏感。

这种判断必须随任务改变。如果指令是“抓红色杯子”，颜色不应被当作可忽略扰动；若任务是“抓离夹爪最近的杯子”，相对距离更重要。遮挡还需单独看：图像没有给出证据的物体状态，不应因为表示数值稳定就被当成确定事实。

## 排查坍缩和看似好看的可视化

把 $B$ 张不同图像的表示放成矩阵 $Z\in\mathbb R^{B\times D}$。若每一行几乎相同，模型基本无法区分这些图像；若只少数维度变化，表示也可能严重退化。可以查看各维标准差、样本间相似度分布，再与位置读取结果对照。标准差不为零只说明存在数值变化，不能证明变化对应杯子而不是背景或采集批次。

二维散点图也有同样限制：把高维特征压到二维会丢信息，几个清楚的簇可能只是不同桌布，杂乱的散点也不一定表示高维空间中完全没有位置线索。实践 04-02 同时展示二维投影、背景对照、位置误差与特征方差；应逐项解释它们各自能证明什么、不能证明什么，而不是挑一幅好看的图作结论。

实践 04-01 还可作另一个交叉检查：AE 的重建可能比较清楚，但其潜变量未必最容易读取杯子中心；VAE 的后验方差是模型内部参数，也不等同于真实相机误差；遮挡重建能完成像素补全，却仍可能忽略机器人需要的接触信息。这些失败并不说明方法没有价值，而是说明**训练题目与使用题目必须分别评价**。

## 把通过检验的编码器交给下一阶段

选择视觉编码器后，还须把它与后续模型之间的约定写清楚。第 03 章已说明全局向量适合整图概括，带位置的特征图或 token 更适合对象定位；这里再加上训练与使用的约定：

| 接口项 | 需要记录的内容 | 忽略它可能造成什么问题 |
| --- | --- | --- |
| 图像预处理 | 分辨率、颜色顺序、归一化 | 输入分布与训练时不同 |
| 表示形状 | $[B,D]$、$[B,N,D]$ 或特征图尺寸 | 下游无法正确读取位置 |
| 编码器更新方式 | 冻结、部分微调或全部更新 | 训练时与使用时的特征含义漂移 |
| 训练任务与数据 | 分类、重建、对比、预测及样本来源 | 把未训练过的信息误当作已保留 |
| 无效区域 | 遮挡、填充和缺失的标记 | 把空白区域当成真实观测 |

若只有少量新任务数据，可先冻结编码器训练下游头，检查现有特征够不够用；若目标信息确实难以读出，再考虑适度微调，并重新测量未见场景表现。微调之后，后续模块收到的数值分布可能改变，所以接口与验证也应更新，而不是把“编码器名称相同”视作完全兼容。

至此，本章从训练目标走到任务检验：监督给出明确答案，AE、VAE 与 MAE 从图像构造重建要求，对比学习规定样本关系，JEPA 式方法预测隐藏特征；任何方法最终都要回答“机器人需要的信息是否保留”。下一章加入语言，讨论文字如何表示任务目标，以及“红色杯子”这样的词怎样与视觉区域建立对应。
