# 机器人状态与动作

## 本章解决什么问题

机器人不是纯视觉系统。本章把本体感觉、末端状态和动作接口写成与图像、语言并列的张量。

## 学习目标

完成本章后，读者应该能够：

- [ ] 区分本体状态、场景状态和动作命令
- [ ] 写出常见动作空间的形状：关节、端位姿、夹爪
- [ ] 说明绝对动作、相对动作和时间上的动作分块会改变接口

## 直观理解

把机器人当成另一个传感器加执行器：状态是当前身体的读数，动作是下一步要发给控制器的命令。

## 输入、输出与张量形状

| 名称 | 符号 | 示例形状 | 含义 |
|---|---|---:|---|
| 本体状态 | s_t | [B, P] | 关节角、速度、夹爪等 |
| 动作 | a_t | [B, A] | 单步动作 |
| 动作分块 | a_{t:t+H} | [B, H, A] | 未来一段动作 |

## 常见误区

- 把仿真器内部状态直接当成真机可观测状态
- 把策略输出的动作和世界模型吃进去的动作写成两套互不兼容的单位

## 它在机器人世界模型中的位置

VLA 的输出端和世界模型的动作条件端都接在这里。接口不稳定，后面所有预测都无法比较。
