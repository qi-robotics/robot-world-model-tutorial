# 语言编码

## 本章解决什么问题

任务往往以自然语言给出。本章讨论语言如何变成 token 与连续表示，为后面的目标条件化做准备。

## 学习目标

完成本章后，读者应该能够：

- [ ] 说明分词、嵌入和语言编码器的分工
- [ ] 区分“描述场景的话”和“作为目标的话”
- [ ] 写出语言特征的典型形状

## 直观理解

语言编码器先把词变成可计算向量；至于它是否真的绑定到场景中的物体，要等到 grounding 与 VLM。

| 名称 | 符号 | 示例形状 | 含义 |

| 语言特征 | z^{lang} | [B, L, D] 或 [B, D] | 序列或句向量 |
