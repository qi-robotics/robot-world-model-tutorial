# 07-3 动作空间与坐标语义

机器人已经能读出自身位置和接触变化，下一步便是把任务意图变成明确的控制命令。“向杯子移动一点”在人看来很自然，控制器却必须知道移动的是哪一部分、用什么单位、相对于哪个坐标系，以及这条命令持续多久。这组约定称为**动作空间**；不同动作空间不能因为输出都是一串数字就直接互换。

## 同一个目标可以写成不同的动作

若要把夹爪移近杯子，模型可以输出一组目标关节角，要求各关节到指定位置；也可以输出末端在基座坐标系中的目标位姿，再交给逆运动学求关节目标。两者描述同一个任务，控制边界却不同。

| 动作形式 | 一条命令的含义 | 典型接口检查 |
| --- | --- | --- |
| 关节位置目标 $q^{*}$ | 各关节要到达的角度或位移 | 关节限位、轨迹速度、可达性 |
| 关节速度目标 $dot q^{*}$ | 各关节在控制周期中的目标速度 | 速度上限、加速度和停止条件 |
| 关节力矩目标 $	au^{*}$ | 施加在关节上的目标力矩 | 力矩限制、动力学与硬件保护 |
| 末端绝对位姿目标 $T^{*}$ | 夹爪相对指定坐标系要到达哪里、朝向如何 | 坐标变换、逆运动学、碰撞检查 |
| 末端位姿增量 $Delta T$ | 从当前末端位姿继续移动多少 | 增量所在坐标系、每步尺度、频率 |
| 夹爪开合命令 $g$ | 打开、闭合或达到指定开度 | 离散/连续含义、接触保护 |

位置目标与速度目标尤其不能混淆。数值 $0.1$ 可以表示“关节目标角度为 $0.1$ 弧度”，也可以表示“以 $0.1$ 弧度/秒转动”；前者需要控制器决定怎样到达，后者还需要持续时间才能确定最终位移。第 07-1 节的雅可比描述关节速度和末端速度在**当前构型附近**的关系，不会自动把任意位姿命令变成安全的关节轨迹。

## 七维末端动作要逐维定义

实践 07-02 使用一条七维教学动作：

$$
a_t=(\Delta x,\Delta y,\Delta z,\Delta r_x,\Delta r_y,\Delta r_z,g)_t.
$$

前三项是基座坐标系中的末端平移增量，单位为米；中间三项是约定旋转表示中的小幅旋转增量，单位为弧度；最后一项是夹爪命令。这里的七维并不是所有机器人的统一标准：另一台机器人可能输出七个关节的目标角、或六维末端运动再加一个二值夹爪信号。数据集和部署端必须共用同一份字段清单，不能只核对张量最后一维等于 $7$。

对于较大的三维旋转，不能把三个旋转分量当成普通位置坐标随意相加。旋转的参数化方式和组合次序也属于动作约定；教学 Notebook 只用小增量说明字段与单位，不承担完整的三维姿态控制。

## “向前两厘米”取决于参照坐标系

假设夹爪自身的前向轴相对机器人基座旋转了 $90^\circ$。同样写作“沿 $x$ 方向前进 $0.02$ 米”，若 $x$ 指**基座坐标系**的轴，目标在基座右方两厘米；若 $x$ 指**夹爪局部坐标系**的前向轴，这一步在基座中可能表现为沿 $y$ 轴前进两厘米。数字和单位完全相同，执行位置却不同。

第 06 章学习的刚体变换用来把这类局部位移转到基座坐标系。部署时应说明是“基座系绝对目标”“基座系增量”还是“末端系增量”，并让训练数据的记录方式与控制器解释方式一致。夹爪指令也有类似问题：$g=1$ 究竟表示打开、闭合、最大开度还是一个归一化数值，必须明确。

动作空间选定后，还不能直接把模型输出送进机器人。一个形式正确的位移也可能因为数值尺度、控制频率或延迟而变得危险。下一节处理从模型空间到实际执行的那段链路。
