# 14 动作条件世界模型：从交互数据预测状态变化

进阶篇已经把观测、动作生成与执行连成一个循环，但机器人只看候选动作数值，仍不知道执行后物体会不会移动、会移到哪里。高级篇首先建立一个最基本的世界模型问题：**当前状态已知，再给定一个动作，预测下一刻发生的变化。** 本章先使用可直接读出的推杆和物体位置，不要求学生同时处理图像编码、视频生成和动作选择。

一条主线贯穿四个小章：先定义预测输入和结果，再从真实交互提取训练样本，接着训练状态转移模型，最后把训练好的模型连续调用并检验误差。

|---|---|
| [14-1 动作条件预测：状态与动作如何决定下一刻](14-1-action-conditioned-prediction.md) | 为什么同一当前状态在不同动作下会有不同后果？世界模型的输入和预测对象是什么？ |
| [14-2 从交互记录构造状态转移样本](14-2-transition-dataset.md) | 哪次观测是执行前状态，哪次是执行后答案，动作应该与哪段时间配对？ |
| [14-3 状态转移模型的训练](14-3-state-transition-learning.md) | 三个输入数怎样经过网络得到两个变化量，误差又怎样更新参数？ |
| [14-4 单步预测、连续展开与模型检验](14-4-one-step-and-rollout.md) | 单步预测准是否足以连续预测？怎样检查接触、动作条件与误差传播？ |

本章共同使用一维推物例子：状态包含推杆和物体的位置，动作表示一个控制周期内推杆的位移。这是为了让输入、答案和预测误差都能算清楚的教学环境，不能代替真实机器人的摩擦与接触动力学。图 14-1 至图 14-4 分别对应“动作导致不同后果”“轨迹拆成样本”“网络训练”“连续展开”，建议按顺序读图。
