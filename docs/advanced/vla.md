# 视觉语言动作模型

## 本章解决什么问题

机器人最终要输出动作。本章把 VLA 定义为：在视觉和语言条件下生成动作的模型，并标明它与世界模型的边界。

## 学习目标

完成本章后，读者应该能够：

- [ ] 写出 VLA 的输入输出合同
- [ ] 对比“直接生成动作”和“先预测未来再规划”
- [ ] 说明开环动作序列与闭环重生成的差别

## 直观理解

看图、读指令、吐出动作。VLA 可以很强，但它默认并不回答“如果这样做，世界会怎样”。

## 常见误区

- VLA 成功演示等于已经具备世界模型
- 把训练时的语言模板当成真实开放指令分布

## 它在机器人世界模型中的位置

闭环图中“生成候选动作”的模块。世界模型将对这些候选进行后果预测；二者不是互相替换。
