# VLA-JEPA

## 本章解决什么问题

VLA-JEPA 要处理的核心结合是：语言与视觉条件下的动作，以及动作条件下的世界预测，如何共享预测式表示而不是变成两套互不相干的网络。

## 从上一章遗留的问题开始

VLA 会生成动作，V-JEPA 会预测视觉表示；二者还没有在教程中被接成同一条预测式架构。

## 直观理解

让模型不仅说出下一步怎么动，还要能在表示空间里想象“动完之后世界是否更接近语言目标”。
