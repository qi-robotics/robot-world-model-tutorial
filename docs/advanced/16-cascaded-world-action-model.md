# 16 级联式世界动作模型：从未来规划到动作执行

第 14、15 章学习的是“已给定动作，预测会发生什么”。机器人接到“把杯子放进盒子”的目标时，却还没有动作可供预测。级联式世界动作模型改变了问题的顺序：先依据当前观测和任务目标形成一段未来计划，再由独立的动作转换模块把计划交给具体机器人执行。本章沿同一杯子任务追踪这两个阶段的输入、输出与执行反馈。

| 小章 | 核心问题 |
| --- | --- |
| [16-1 级联式世界动作模型的结构与接口](16-1-cascaded-architecture.md) | 为什么“给定动作预测后果”不能直接回答“给定目标怎样行动”？两阶段在哪里相接？ |
| [16-2 目标条件的未来计划生成](16-2-goal-conditioned-future-plan.md) | 未来画面或视觉特征怎样成为计划？训练时的真实未来与使用时设想的未来有什么区别？ |
| [16-3 从未来计划到机器人控制动作](16-3-plan-to-robot-action.md) | 计划里的视觉变化怎样转换为机器人命令？逆动力学模型与几何转换分别做什么？ |
| [16-4 UniPi 案例与执行反馈](16-4-unipi-and-feedback.md) | 一个具体级联系统怎样接起两段模块？执行结果偏离计划时该用哪份观测继续？ |

“级联”说明**未来生成模块的输出成为动作转换模块的输入**，不意味着所有模型必须使用同一种视频生成网络、逆动力学模型或控制器。16-4 以 UniPi 作为贯穿实例；VERA 和 AVDC 只用于比较第二阶段的不同实现，不替代主线。图 16-1 至图 16-4 分别对应问题转换、未来计划、动作接口和完整实例，建议按顺序读图。
