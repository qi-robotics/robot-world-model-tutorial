# Sim-to-Real

## 本章解决什么问题

仿真提供可重置、可安全试错的数据，真机提供真实物理。本章讨论这条迁移接口，以及它如何改变编码器、动力学和动作延迟的设计。

## 常见误区

- 视觉更像真实就等于动力学已经对齐
- 忽略控制频率、通信延迟和夹爪物理

## 它在机器人世界模型中的位置

若世界模型只在仿真里准，规划器在真机上就会选错动作。这一章把“模型误差”变成部署问题。
