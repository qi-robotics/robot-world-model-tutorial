# 15 视觉世界模型：预测表征，还是生成未来画面？

第 14 章直接用推杆和物体的位置学习“当前状态＋实际动作 → 下一状态”。进入第 15 章，相机只给出图像，物体位置并非现成输入。模型仍要从实际发生的交互中学习动作的后果，但现在必须先决定未来怎样表示，再决定视觉编码器和预测器各自怎样训练。最后还要核对：模型预测的变化是否真的与推动任务有关。

本章拆为四个相继的问题，沿用同一个推动 T 形物体的例子。

| 小章 | 核心问题 |
| --- | --- |
| [15-1 视觉预测的对象与训练关系](15-1-visual-prediction-targets.md) | 下一刻可以表示成物体坐标、图像或视觉特征；当前图像、实际动作、真实未来图像怎样组成训练样本？ |
| [15-2 固定编码器的动作条件表征预测](15-2-frozen-visual-encoder.md) | 视觉编码器固定后，预测器怎样从当前特征和动作学习未来特征？DINO-WM 属于怎样的训练安排？ |
| [15-3 联合训练视觉编码器与预测器](15-3-joint-visual-learning.md) | 让编码器一起学习为何可能发生表征坍缩？LeWM 的预测误差与 SIGReg 分别检查什么？ |
| [15-4 未来画面生成与视觉预测检验](15-4-generative-visual-futures.md) | 从噪声生成视觉未来与预测未来特征有何不同？怎样核对动作、接触和连续预测是否正确？ |

四节中，**当前观测 → 实际动作 → 真实未来观测**的时间顺序不变。前两种表征学习安排关注编码器是否固定；生成式路线则更换了输出对象。无论输出特征还是画面，本章模型都只预测**已给定动作的后果**，不自动生成机器人命令。第 16 章会从这个界限出发，讨论未来计划怎样进一步连接动作。
