# 泛化

## 本章解决什么问题

新物体、新指令、新布局和新人是机器人系统最常见的失败来源。本章把泛化拆到表示、语言、动作和动力学各层。

## 学习目标

完成本章后，读者应该能够：

- [ ] 区分视觉外观泛化、语言组合泛化和动力学泛化
- [ ] 说明应该在哪一层做检查，而不是只看任务成功率
- [ ] 列出本教程闭环中最容易断的接口
