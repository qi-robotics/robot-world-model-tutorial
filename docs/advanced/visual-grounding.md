# Visual Grounding

## 本章解决什么问题

语言中的物体和位置必须落到视觉空间里，机器人才能知道抓哪里、放哪里。本章讨论 grounding 的接口。

VLM 可以产生关于图像的语言，但执行器需要的是场景中的位置与对象，而不是一段话。

## 直观理解

把“那个红色杯子”翻译成图像里的区域或点。这是语言目标进入几何世界的接口。

## 常见误区

- 检测框正确就认为抓取点正确
- 忽略遮挡、物体堆叠和相机外参

## 它在机器人世界模型中的位置

它把语言目标钉到当前观测的空间结构上。没有这一步，VLA 很容易学会语言和动作的虚假相关。
