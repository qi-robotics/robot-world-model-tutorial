# 视觉语言模型

## 本章解决什么问题

语言要成为任务接口，模型必须能就图像回答、描述或推理。本章进入 VLM，把它定位成视觉世界的语言接口，而不是动作策略。

## 直观理解

VLM 让模型用语言谈论图像：这是什么、在哪里、能不能抓。它输出的是词，不是关节角。

## 常见误区

- 能描述场景就等于能操作场景
- 把提示词工程当成已经解决视觉定位

## 它在机器人世界模型中的位置

它负责把语言目标接到视觉编码之上。真正的动作生成在 VLA；真正的后果预测在世界模型。
