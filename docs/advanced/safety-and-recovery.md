# 安全与失败恢复

## 本章解决什么问题

闭环最后一段不是成功演示，而是失败时如何约束动作、恢复或请求停机。本章把安全控制接到规划与真机部署。

## 学习目标

完成本章后，读者应该能够：

- [ ] 区分约束、监测、急停和任务级恢复
- [ ] 写出安全层在动作发出前截获的接口
