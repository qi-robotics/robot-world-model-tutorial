# Attention

## 本章解决什么问题

历史和当前观测里并非所有信息都同等重要。本章说明注意力如何按查询选择相关内容。

## 常见误区

- 把注意力权重直接解释成人类意义上的“看懂了”
- 忽略掩码导致的因果泄漏或未来泄漏

## 它在机器人世界模型中的位置

多模态融合、Transformer、VLM 和预测器都会反复使用这个算子。它本身还不是世界模型。
