# 多模态融合

## 本章解决什么问题

视觉、语言和本体状态进入模型后，需要一种明确的融合接口。本章讨论拼接、交叉注意力和其他融合方式各自补什么缺口。

## 从上一章遗留的问题开始

Transformer 能消化 token 序列，但还没有约定多模态 token 如何排在一起、谁查询谁。

## 直观理解

融合不是把向量加起来这么简单：要先决定谁是查询、谁是被查询，以及融合后的状态叫什么。

| 状态 | s | [B, P] | 本体感觉 |

## 常见误区

- 不同模态已经对齐到同一维度，就等于已经融合
- 让强势模态（通常是语言或整图）静默覆盖空间细节
