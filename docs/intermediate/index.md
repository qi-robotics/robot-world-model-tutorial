# 进阶篇：世界如何变化

核心问题：

> 模型如何理解上下文、时间和动作，并预测未来可能发生什么？

基础篇解决的是“当前世界如何被写成 \(z_t\)”。进阶篇开始处理时间和变化：模型必须能关联历史、表达多个未来，并初步把预测用于控制。

## 本阶段要打通的能力

```text
特征如何表示当前状态
→ 模型如何关联历史信息
→ 模型如何表达多个未来
```

```mermaid
flowchart LR
    H["历史观测与动作"] --> C["上下文建模"]
    C --> P["未来预测"]
    P --> U["单峰 / 多峰未来"]
    U --> Ctrl["基于模型的控制"]
```

## 学完进阶篇应该能解释

- [ ] Attention 解决的是“全连接地混合所有信息”的什么问题
- [ ] 自回归和 Diffusion 分别适合表达什么样的未来
- [ ] 为什么世界模型常常在 latent 空间而不是像素空间做多步 rollout
- [ ] 预测模型怎样接到 MPC 或 model-based RL，但仍缺少语言目标

## 本阶段结束后留下的问题

现在模型开始能写：

$$
p(z_{t+1}\mid z_t,a_t)
$$

但它还不能稳定地回答：

- 语言任务如何指定目标？
- 动作如何从视觉语言条件中生成？
- 预测后果之后，谁来选择动作，失败了如何恢复？

这些问题交给 [高级篇](../advanced/index.md)。
