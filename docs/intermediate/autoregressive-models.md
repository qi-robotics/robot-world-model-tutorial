# 自回归生成

## 本章解决什么问题

许多模型通过“下一步再下一步”写出未来或动作。本章说明自回归生成的接口、教师强制及其局限。

时间模型可以编码历史，但还没有一种生成接口去产生尚未发生的 token。

## 直观理解

每次只决定下一个符号，并把这个符号塞回上下文。动作 token、下一帧 token 都可以这样写。

## 常见误区

- 教师强制训练成功就等于闭环生成稳定
- 把离散 token 化当成对连续动作无损耗

## 它在机器人世界模型中的位置

VLA 的动作 token 解码、部分视频预测和语言条件规划都会用到这个接口。它善于给一条轨迹，不一定善于同时表达多种未来。
