# 10 多模态 Context Model

第 08 章说明机器人为什么需要历史，第 09 章说明怎样从历史中的不同位置读取信息。来到第 10 章，还要解决一个更具体的问题：相机、语言、本体状态和触觉怎样共同告诉机器人“现在要针对哪个物体、处于任务的哪一步”？这些输入最终必须形成可供动作模型使用的 Context，而不能只是一堆并排放置的数字。

本章始终用同一个桌面任务串联：左边是红方块，右边是蓝方块，机器人按照指令拿起指定方块并放入盒中。先保证每次决策只使用当时可用的传感器记录；再让指令、画面和身体信号共同形成任务条件表示；最后通过训练样本和更换指令、遮挡模态等对照，检查模型是否真的用到了应有的信息。

| 小章 | 主要内容 | 学完后能够说明 |
|---|---|---|
| [10-1 从传感器记录到多模态 token](10-1-time-alignment-and-tokens.md) | 按时间戳对齐观测，标明模态、来源和有效位 | 一次决策究竟能读取哪些输入，以及掉帧与补齐有何区别 |
| [10-2 多模态 Context 的构建](10-2-multimodal-fusion.md) | 指令与视觉目标对应，再结合夹爪和触觉；确定交给动作模型的表示 | 为什么相同画面换一条指令，会形成不同的任务条件 |
| [10-3 Context Model 的训练与验证](10-3-context-training-and-validation.md) | 区分输入与示范答案，用目标交换和模态遮挡检查模型行为 | 损失下降之外，还怎样判断模型确实使用了相关证据 |

实践 10-01 配合 10-1 检查时间、token 与 mask；实践 10-02 配合 10-3 训练一个简化的目标条件判断模型。这两份实验各自回答一个教学问题，并不宣称已训练好完整机器人策略。完成本章后，第 11 章将接着讨论动作怎样表示，以及 Action Model 怎样利用 Context 学习示范动作。
