## 本章解决什么问题

有了预测，还需要一种把预测变成动作选择的机制。本章引入 MPC 与 model-based RL 的接口，但不提前给出算法排名。

## 直观理解

在想象里试几条动作，看哪条让预测中的未来更接近目标，再把第一步发给机器人。
