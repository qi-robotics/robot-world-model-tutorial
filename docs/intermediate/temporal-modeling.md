# 时间序列建模

## 本章解决什么问题

操作是时间过程。本章讨论如何把当前状态扩展成对历史的依赖，为生成和动力学做准备。

## 直观理解

给状态加上时间轴：模型看到的不再是一张照片，而是一段轨迹。

## 常见误区

- 把帧率、控制频率和模型步长混成同一个 \(t\)
- 在训练时看到未来帧，却把它当成因果预测
