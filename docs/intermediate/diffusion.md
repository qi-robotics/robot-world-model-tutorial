# Diffusion

## 本章解决什么问题

连续、多峰的未来或动作分布往往难以用单次回归或单条自回归轨迹表达。本章引入扩散模型作为另一种生成接口。

## 学习目标

完成本章后，读者应该能够：

- [ ] 说明噪声、去噪和条件化的基本流程
- [ ] 对比自回归“逐步写 token”和扩散“逐步去噪”
- [ ] 指出推理步数、条件方式和动作维度如何进入接口

## 从上一章遗留的问题开始

上一章：[自回归生成](autoregressive-models.md)。

自回归适合逐步写出离散序列，但对连续动作分布和多峰未来并不总是自然。

## 直观理解

先把目标变成噪声，再学习在条件（图像、语言、状态）下把噪声还原回去。

- 把采样步数当成唯一质量旋钮
- 在需要精确低维控制时，默认扩散一定优于回归
