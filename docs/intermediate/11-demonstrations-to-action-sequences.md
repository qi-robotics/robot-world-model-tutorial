# 11 从示范到动作序列

第 10 章已经把当前及过去的观测、任务目标整理成 Context。接下来机器人需要回答：“在这个情境下，示范者怎样行动？”答案不能只是一个没有单位的数字。示范包含一条连续轨迹，动作有控制空间和时间含义，模型一次可能预测多步，而同一情境下也可能有不止一条成功路线。本章从最简单的示范学习开始，逐步建立第一个 Action Model，并说明它为什么还需要第 12 章的生成式方法。

我们继续使用“拿红色方块并放入盒子”的任务：先确定示范动作到底是什么、从哪一时刻开始；再训练模型根据 Context 预测未来动作块；然后区分预测一段与实际执行一段；最后在路径出现上下两种绕障示范时，检查单一预测会发生什么。

| 小章 | 主要内容 | 学完后能够说明 |
|---|---|---|
| [11-1 示范轨迹与动作标签](11-1-demonstrations-and-action-labels.md) | 动作的物理语义、时间对齐与训练窗口 | 一条训练样本的输入、未来答案和有效位分别是什么 |
| [11-2 行为克隆与动作块预测](11-2-behavior-cloning.md) | 第一个 Action Model、动作块输出与带有效位的损失 | 模型怎样从 Context 学到确定的未来动作块 |
| [11-3 动作块的执行与反馈](11-3-action-chunk-execution.md) | 观察、预测、执行长度和重叠动作块 | 为什么预测八步可以只执行前两步，再依据新观测修正 |
| [11-4 多种合理动作与单值预测的局限](11-4-multimodal-actions.md) | 双路线示范、均值动作与动作分布 | 为什么更低的数值误差不一定产生可执行轨迹 |

实践 11-01 配合 11-1 与 11-3 检查切窗、动作块融合和滚动执行；实践 11-02 配合 11-4 比较单值预测与两种绕障模式。两份实验都保持教学规模，结果须按其动作表示和任务条件解读。第 12 章将沿用本章确定的 Context、动作块和执行接口，只改变动作块**怎样生成**。
