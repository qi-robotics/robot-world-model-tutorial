# 08 时间与记忆

基础篇建立了视觉、语言、本体、触觉和动作的逐时刻接口。但机器人判断杯子是否抓稳时，仅知道夹爪此刻在什么位置仍然不够：它还要知道刚才是否接触杯子、夹爪怎样闭合、抬起后杯子是否随动。同一个当前画面，可能来自不同的交互历史。

本章把“使用历史”拆成四个连续的问题。先将交互记录整理为因果顺序正确的时间序列，再分别学习普通 RNN、LSTM 和 GRU 如何沿时间更新内部记忆。我们始终以“根据过去的触觉和动作，判断抓取是否稳定”为贯穿例子：模型结构会变，但输入记录与任务含义尽量保持一致，这样才能看清各方法的差异。

| 小章 | 本节回答的问题 | 阅读后的具体能力 |
|---|---|---|
| [08-1 从交互轨迹到时间序列样本](08-1-temporal-sequences.md) | 哪些历史在当前时刻真正可用？ | 从轨迹整理窗口、标签、时间戳与有效位，辨认动作和观测错位 |
| [08-2 循环神经网络：让隐藏状态沿时间更新](08-2-rnn.md) | 一个隐藏状态怎样把过去传到当前？ | 手工追踪多步 RNN 的输入、隐藏状态与输出，说明普通 RNN 的记忆局限 |

前一小章得到的时间序列样本，是后三种模型的共同输入；模型比较不能脱离数据是否对齐、任务是否真的依赖历史。两份已有实践分别放在 08-2 的手工循环计算和 08-4 的模型对照处。学习这一组内容后，再进入第 09 章：如果需要读取久远的某个时刻，而不是只依赖最后一个隐藏状态，模型应怎样选择历史中的相关信息？
