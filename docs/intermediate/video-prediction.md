# 视频预测

## 本章解决什么问题

机器人改变的是随时间展开的视觉世界。本章讨论预测未来帧或未来视觉表征会遇到的接口问题。

## 直观理解

给模型当前一段视频和可选动作，让它想象接下来几帧。这是世界模型最直观、也最容易在像素上失败的版本。
