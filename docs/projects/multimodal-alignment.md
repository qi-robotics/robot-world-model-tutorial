# 多模态对齐小项目

## 本章解决什么问题

让图像和短指令进入可比较空间，并检查检索是否依赖捷径。

## 学习目标

完成本项目后，读者应该能够：

- [ ] 给定句子能找回对应图像，或反过来
- [ ] 至少做一次捷径检查，例如背景泄漏
- [ ] 写下这个共享空间还不能做的事
